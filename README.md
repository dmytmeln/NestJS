# Платформа для організації подій (Event Management Platform)

---

## Технології

NestJS, TypeScript, PostgreSQL

---

## Опис проєкту

Веб-платформа для для повноцінного управління живими та онлайн-подіями (конференціями, воркшопами, вебінарами).

---

## Основний функціонал:

### Аутентифікація та користувачі

- Реєстрація та вхід користувачів (JWT).
- Підтримка ролей: Admin, Organizer, Attendee.

### Управління подіями

- Створення, редагування, публікація та видалення подій.
- Збереження ключової інформації: назва, опис, локація, час, статус.
- Автоматичне оновлення статусу події (live/past) за розкладом.

### Розклад (Sessions)

- Додавання сесій (доповідей, воркшопів) до подій.
- Призначення часу, спікерів, залів або посилань до сесій.
- Автоматична зміна статусу сесій (upcoming → live → completed).

### Учасники (Attendees)

- Реєстрація користувачів на події (безкоштовні та платні).
- Видача квитків після успішної реєстрації (платної або безкоштовної).
- Подивитися всіх учасників події.

### Квитки

- Генерація унікальних квитків (QR-код або код підтвердження).

### Спікери

- Додавання та редагування профілів спікерів (ім’я, біо, фото).
- Прив’язка спікерів до сесій та подій.

### Сповіщення

- Відправка нагадувань учасникам (наприклад, за 24 години до початку).
- Email сповіщення про оновлення розкладу чи статусу.

### Керування файлами

- Завантаження фотографій спікерів, логотипів подій.
